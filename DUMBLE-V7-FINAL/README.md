## 🎮 Comment Jouer

1. **Cliquez sur vos cartes** pour les sélectionner (max 4)
2. **Cliquez "Défausser"** pour les jeter
3. **Voyez la défausse jaune** du joueur précédent
4. **Piochez** une carte (défausse verte ou paquet)
5. **Joueur suivant** 🔄
